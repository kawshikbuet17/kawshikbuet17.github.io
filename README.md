## � Content Structure

| Directory | Purpose |
|-----------|---------|
| `content/` | Site content (TOML, Markdown, BibTeX) |
| `public/` | Static assets (images, files) |
| `src/` | Source code |

## � Configuration

Edit files in `content/` to customize:
- `config.toml` - Site metadata, navigation, social links
- `about.toml` - Profile, research interests
- `bio.md` - About page content
- `publications.bib` - Publications
- `research.toml`, `projects.toml`, `news.toml` - Page configs
